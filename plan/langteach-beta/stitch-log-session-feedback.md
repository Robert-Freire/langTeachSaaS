# Log Session — Stitch revision prompt

Paste this in the Stitch conversation after the current Log Session screen.

~~~
Changes needed for the Log Session screen:

1. ADD a "Previous Homework Status" field. The teacher needs to record
   whether the student actually did last session's homework. Place it
   above or beside "Homework Assigned" as a small select or segmented
   control with three options: Done / Partial / Not Done. This is a
   separate field from the homework being assigned THIS session.
   Currently the form only captures what homework is given, not whether
   the previous one was completed.

2. EXPAND the Objectives section in the left context panel. Right now
   it shows only one "Current Goal" (DELE B2 Preparation). It should
   show ALL active Short-Term Objectives as a list, each with its
   target date. Objectives within 6 weeks of deadline get an amber
   highlight. Past-due objectives get a red "OVERDUE" label. The
   teacher needs to see the full picture of time-pressured goals
   while logging, not just the first one.

3. RENAME "Session Notes" to "Today's Context". The current label
   could be confused with the main session narrative ("What
   Happened?"). The placeholder text is good ("Observations on mood,
   energy levels, and general context...") but the heading should
   make it clear this is about the student's state today, not the
   session content. Use "Today's Context" or "Session Context."

4. VERIFY that the Teaching Todos and Pending Followups cards in the
   middle area are accessible without scrolling away from the "What
   Happened?" textarea. The teacher will want to add a todo or
   followup while writing the narrative. If scrolling is required,
   consider moving the quick-add inputs for new todos and followups
   to the right column (form side), below "Next Session Plan."

5. KEEP the reference line under "What Happened?" that shows the
   planned content ("Reference: Narrating past events, Por vs Para").
   This is exactly right. It's read-only context from the previous
   session's "next session plan." Do not make it editable.

Everything else looks great. Keep the two-column layout, the student
context panel (name, level, L1, current goal, teaching todos,
pending followups, last session summary, planned for today, active
difficulties), the voice note section with Record + Upload +
Transcription Ready, the date/duration/cancelled row, the "What
Happened?" as the dominant textarea, homework + next session plan
side by side, topics covered tags, link to lesson plan search,
and the Level Check toggle at the bottom.
~~~
